================================================================================
                        WHAT THE SYSTEM DOES
================================================================================

GlyphDepthAdjuster (Per-Glyph):
  ✓ Listens for transition events
  ✓ Stores background depth (z=1) and interaction depth (z=0)
  ✓ Updates Z-position when appropriate
  ✓ Can be enabled/disabled per glyph
  ✓ Handles timing (waits for fade to complete)

GlyphDepthAdjusterTrigger (Scene-Wide):
  ✓ Finds all GlyphDepthAdjuster components in scene
  ✓ Broadcasts transition events to all adjusters
  ✓ Provides scene-level control API
  ✓ Auto-creates itself if not present

DialogueTransitionFade (Integration Point):
  ✓ Detects GlyphDepthAdjusterTrigger
  ✓ Calls OnTransitionStarted() when fade begins
  ✓ Calls OnTransitionCompleted() when fade-in finishes
  ✓ Fully backward compatible (no breaking changes)

================================================================================
                          HOW IT WORKS
================================================================================

Z-Position States:

  ┌────────────────────────────────────────────┐
  │ BACKGROUND STATE (z=1.0)                   │
  ├────────────────────────────────────────────┤
  │ Glyph is behind debris                     │
  │ No collision with player                   │
  │ NOT interactable                           │
  │ Player can walk through freely             │
  └────────────────────────────────────────────┘
           ↓ (During fade transition)
  ┌────────────────────────────────────────────┐
  │ INTERACTION STATE (z=0.0)                  │
  ├────────────────────────────────────────────┤
  │ Glyph is at player layer                   │
  │ In player's interaction space              │
  │ FULLY interactable                         │
  │ Player can E to collect                    │
  └────────────────────────────────────────────┘

Timing:
  T=0.00s: Dialogue complete
  T=0.00-1.2s: Fade to black (glyph position hidden)
  T=1.2s: Screen fully black
           → Debris disabled
           → Sphere Collider enabled
           → GlyphDepthAdjuster.OnTransitionStart() fires
  T=1.2-2.0s: Hold on black screen (scene rearrangement)
  T=2.0-3.2s: Fade back in (screen gradually visible)
  T=3.2s: Fade complete
          → GlyphDepthAdjuster.OnTransitionCompleted() fires
          → Coroutine waits 0.3 seconds
  T=3.5s: Glyph Z updates: z=1.0 → z=0.0 (invisible!)
  T=3.5s+: Player can interact with glyph

Result: No visible pop-in, perfect visual flow!
