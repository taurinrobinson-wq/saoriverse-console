# **2. The trick is: don’t change global gravity. Change *local forces*.**

If you change Unity’s global gravity, everything breaks:

- NPCs fall through floors  
- props behave weirdly  
- physics becomes unpredictable  

But you don’t need to touch global gravity at all.

Instead, you apply **additional downward force only to the player**.

### **Implementation idea (simple, stable):**
- Keep global gravity at default.  
- Add a “SorrowWeight” component to the player.  
- When the player absorbs Sorrow, increase a downward force applied each frame.  
- This creates the feeling of heaviness without breaking physics.

This is literally just:

```
playerRigidbody.AddForce(Vector3.down * sorrowWeightForce);
```

Or, if using CharacterController:

- Increase downward velocity  
- Lower jump height  
- Increase slope friction  
- Slightly tilt the camera downward (subtle but powerful)

This gives the “top‑heavy, pulled down” feeling without chaos.

# **3. The gravity‑well effect is absolutely doable — and brilliant**
You don’t need real gravity wells.  
You need **area‑of‑effect debuffs** that *feel* like gravity.

### **How to simulate a gravity well without breaking physics:**

When the player has enough Sorrow:

- Create a sphere collider around them (trigger only).  
- Any NPC inside the sphere gets:
  - reduced movement speed  
  - lowered animation speed  
  - slight downward head tilt  
  - heavier footstep sounds  
  - slower turning  

This *feels* like gravity.  
It *reads* like gravity.  
But it’s just modifying movement parameters.

### **Optional visual cues:**
- subtle vignette  
- slight camera dip  
- dust particles pulling inward  
- cloth sim on NPCs drooping  

All low‑risk, high‑impact.
