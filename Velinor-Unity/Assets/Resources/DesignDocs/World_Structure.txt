## **2. Import and Normalize Assets**

**Task:**  
For each asset pack, Codespace must import it into the correct biome folder and normalize materials, naming, and prefabs.

**Instructions to Codespace:**

```
For each imported Unity package, perform the following steps:

1. Import the package into a temporary folder under Assets/_ImportedRaw/[PackageName].

2. Move ONLY the following into the appropriate biome folder:
   - Models
   - Materials
   - Prefabs
   - Textures

3. Rename all imported assets using the format:
   [Biome]_[AssetType]_[OriginalName]

   Example:
   Rural_Tree_Oak01
   Ruined_Column_BrokenA
   Deep_CaveWall_01
   Corelink_Panel_LightStrip01

4. Convert all materials to URP-compatible materials using Unity’s material upgrader.

5. Delete the _ImportedRaw folder after normalization.
```

## **3. Create Biome Prefab Libraries**

Each biome needs a **Prefab Library** that Velinor can pull from during scene construction.

**Instructions to Codespace:**

```
For each biome folder, create a PrefabLibrary.asset ScriptableObject at:
Assets/World/[Biome]/PrefabLibrary.asset

The ScriptableObject must contain:

- A list of prop prefabs
- A list of terrain detail prefabs (trees, rocks, foliage)

Expose these lists in the inspector for manual assignment.
```

## **5. Implement Biome Managers**

Each biome needs a **BiomeManager** component that controls lighting, fog, color grading, and ambient audio.

**Instructions to Codespace:**

```
Create a BiomeManager.cs script with the following responsibilities:

- Holds references to:
  - Lighting profile
  - Fog settings
  - Ambient audio
  - Post-processing profile
  - Weather controller (optional)

- Provides a public method:
  ApplyBiomeSettings()

- When ApplyBiomeSettings() is called:
  - Set RenderSettings.ambientLight
  - Set fog color and density
  - Apply post-processing profile
  - Trigger ambient audio

Create four derived classes:
- RuralBiomeManager.cs
- RuinedBiomeManager.cs
- DeepBiomeManager.cs
- CorelinkBiomeManager.cs

Each derived class overrides default settings with biome-specific values.
```

---

## **6. Create Biome Transition System**

This allows the player to move between Rural → Ruined → Deep → Corelink without hard scene loads.

**Instructions to Codespace:**

```
Create a BiomeTransitionTrigger.cs script with:

- public BiomeManager targetBiome;
- OnTriggerEnter:
    targetBiome.ApplyBiomeSettings();

Place this script on trigger volumes in the world.

Ensure the system supports:
- Smooth lighting transitions
- Smooth fog transitions
- Smooth audio transitions
```
