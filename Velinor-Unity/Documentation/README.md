# Velinor Console Documentation

Organized reference materials for the Velinor game project.

## Folder Structure

### 📖 Lore
**Canonical world-building and narrative documentation**
- Character histories
- System mechanics (Corelink, Codex, glyphs)
- Environmental narratives
- Thematic frameworks

### 🔧 Setup
**Configuration and implementation guides**
- Scene setup tutorials
- System initialization
- Component configuration
- Step-by-step walkthroughs

### ⚙️ Systems
**Technical system documentation**
- Dialogue system specifications
- Input handling
- Map systems
- Architectural patterns

### 🔍 Reference
**Troubleshooting and optimization**
- Error resolution
- Asset management
- Debugging guides
- Performance optimization

## Contributing

When adding new documentation:

1. Choose the appropriate folder based on content type
2. Use clear, descriptive filenames (UPPERCASE_WITH_UNDERSCORES.md)
3. Include a header that explains the document's purpose
4. Link to related documents where relevant
5. Keep technical documentation separate from lore
